# Funcionalidades Mínimas

La API debe permitir:

### Usuarios
- Crear usuarios.
- Consultar usuarios.
- Activar e inactivar usuarios.

### Recursos
- Crear recursos.
- Modificar recursos.
- Consultar recursos.
- Cambiar el estado de un recurso.

### Reservas
- Crear reservas.
- Cancelar reservas.
- Consultar reservas por usuario.
- Consultar reservas por recurso.
- Consultar reservas por fecha.
- Consultar disponibilidad de un recurso.
