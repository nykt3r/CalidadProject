# Reglas de Negocio Obligatorias

El sistema deberá garantizar como mínimo que:

1. Un usuario inactivo no puede realizar reservas.
2. Un recurso en mantenimiento no puede ser reservado.
3. Un recurso fuera de servicio no puede ser reservado.
4. La fecha final de una reserva debe ser posterior a la fecha inicial.
5. No pueden existir dos reservas superpuestas para el mismo recurso.
6. Una reserva ya finalizada no puede cancelarse.
7. No se pueden realizar reservas para fechas anteriores al momento actual.
8. Un usuario no podrá tener más de **3 reservas activas simultáneamente**.
