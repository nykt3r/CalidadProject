# Condiciones de Calidad

El proyecto debe quedar preparado para aplicar posteriormente:

- SonarQube.
- JUnit.
- Mockito.
- PIT Mutation Testing.
- Postman.
- JMeter.

## Escenario futuro de carga

El sistema deberá soportar posteriormente una prueba donde:

> 500 usuarios intentan reservar simultáneamente un conjunto limitado de recursos.

El sistema **nunca** deberá permitir reservas duplicadas.
