# Proyecto 1 — Sistema de Reservas de Espacios y Recursos

## Contexto

Una institución necesita un sistema que permita administrar la reserva de espacios y recursos compartidos, como laboratorios, auditorios, salas de reuniones, equipos audiovisuales y otros elementos.

Actualmente las reservas se realizan de manera manual, lo que puede generar problemas como reservas duplicadas, conflictos de horarios, recursos reservados mientras están en mantenimiento o usuarios con demasiadas reservas simultáneas.

El equipo deberá desarrollar una **API REST en Java con Spring Boot** que permita controlar este proceso.

## Objetivo

Construir una API REST capaz de administrar usuarios, recursos y reservas, aplicando reglas de negocio que garanticen la correcta disponibilidad de los recursos.

El sistema será utilizado posteriormente para realizar actividades de calidad de software, pruebas automatizadas, análisis estático, mutation testing y pruebas de rendimiento.

## Tecnologías mínimas

El proyecto deberá desarrollarse utilizando:

- Java 17 o superior.
- Spring Boot (API REST).
